# Columbina-inspired UI research

This folder contains web-sourced visual references for a possible redesign of the NutritionDetection app. It is research material only; no application code has been changed.

## Proposed visual direction

- **Base:** deep blue-black / ink rather than pure black
- **Primary surfaces:** porcelain white and cool mist-blue panels
- **Accent:** muted rose-pink for active states and assistant personality
- **Signal accent:** restrained crimson for warnings, streak breaks, or important nutrition gaps
- **Secondary accent:** desaturated sky blue for charts, progress, and “calm” system states
- **Mood:** quiet, celestial, elegant, soft, and observant; avoid loud cyberpunk neon

## Design observations

### Chatbot

- Keep the conversation area spacious and readable.
- Make Columbina’s presence visible through a small portrait/crest, soft pink state indicator, and gentle voice orb—not through dense decoration.
- Use a left rail for conversation history and a compact context panel only when it helps the nutrition task.
- Treat attachments and meal scans as first-class message cards.

### Dashboard

- Lead with “today” and one clear calorie/goal story.
- Use a large circular or arc progress visualization, followed by protein/carbs/fat cards.
- Add recent scans / meals as a timeline so the dashboard feels like a personal journal, not an admin console.
- Reserve crimson for under-target or caution states; do not use it as a general accent.
