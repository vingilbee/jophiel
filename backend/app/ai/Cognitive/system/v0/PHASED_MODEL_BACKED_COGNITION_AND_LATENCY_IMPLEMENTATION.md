# Earlier phased cognition experiment: reference

The October 4 implementation assignment is superseded as a work plan. Use the
[current guide](README.md) for architecture, open issues and priorities.

The experiment introduced model-backed appraisal and compact context-conditioned
calls around the deterministic state/goal/action infrastructure. The current V1
route separates Action selection from Realization and may invoke contribution;
old “exactly two calls including wording” targets do not describe all V1 turns.

Evidence is retained in the [Phase 1 report](PHASE_1_MODEL_APPRAISAL_IMPLEMENTATION_REPORT.md),
[compact implementation report](COMPACT_TWO_CALL_IMPLEMENTATION_REPORT.md),
[compact behavioral report](COMPACT_TWO_CALL_BEHAVIORAL_REPORT.md), and
[compact size/latency record](COMPACT_TWO_CALL_LATENCY_REPORT.md).
Those records distinguish scripted checks from real-provider measurements.

Latency, correctness and conditioning quality require separate measurements on
the selected protocol. No historical phase name or passed contract check proves
current teacher quality, deployment readiness, or a latency target.
