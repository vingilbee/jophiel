# Immediate adaptation

Status: proposed plan, not implementation authorization. [Plan index](README.md).

## Outcome

A correction changes a later relevant decision without changing weights.

Dependencies: Step 2.

## Work

- Keep current-action selection in cognition and memory writes with existing memory owners.
- Design scoped lessons with revisions, exceptions, counterevidence, withdrawal, and user ownership.
- Add compatible learner inputs and record which lesson revisions each consumer saw; coordinate Student 2 schema changes with training.
- Build a conversational correction walkthrough with an unseen related situation and an exception.

## Decisions to settle within this plan

Explicit versus inferred lesson acceptance; conflict precedence; retrieval budget; Student 2 migration; handling incompatible models.

## Completion evidence

Show a relevant later choice using the accepted correction, an unrelated choice remaining unaffected, and a withdrawn lesson no longer used. Mouth-only adaptation cannot stand in for Student 2 adaptation.
