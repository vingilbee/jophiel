# Predictions and bounded game trials

Status: proposed plan, not implementation authorization. [Plan index](README.md).

## Outcome

An experiment compares a pre-action prediction with observed effects.

Dependencies: Step 2; coordinate lesson interfaces with step 3.

## Work

- Reuse existing game practice and skill evaluation.
- Record hypothesis, alternatives, predicted observations, uncertainty, observation window, costs, and stop conditions before execution.
- Cognition selects; bodies execute; learning assesses and revises through existing owners.
- Keep simulated outcomes separate and absent observations unresolved.

## Decisions to settle within this plan

Initial predictor; candidate generation; trial budgets; stop rules; observation coverage; supported game scenario.

## Completion evidence

Complete a bounded trial and evaluate from a changed starting condition. Preserve inconclusive results and competing explanations.

## Boundary

Broader interpersonal experimentation is a separate design decision, not implicitly enabled by this game implementation.
